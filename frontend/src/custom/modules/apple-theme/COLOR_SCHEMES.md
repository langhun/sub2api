- 流体：天蓝 → 亮蓝 → 浅蓝
- 卡片：白色半透明玻璃

**深色模式：**

- 流体：深蓝 → 中蓝 → 石板灰
- 卡片：深蓝半透明玻璃

## 如何切换主题

这些配色是设计参考，不是用户侧可选主题。正式启用的全局配色必须通过管理后台设置并由服务端公开配置下发；浏览器本地存储不能覆盖主题风格。

---

## 配色设计理念

基于 [Glassmorphism UI 最佳实践](https://www.clay.global/blog/glassmorphism-ui)：

1. **背景要丰富** - 流体渐变提供足够的颜色层次让玻璃效果生效
2. **透明度适中** - 20-40% 透明度，不会太模糊也不会太透明
3. **模糊度平衡** - 20px 模糊，清晰度和层次感的最佳平衡
4. **对比度达标** - 所有配色都满足 WCAG 4.5:1 对比度标准
5. **性能优先** - 使用 CSS 变量，切换主题无需重新加载
