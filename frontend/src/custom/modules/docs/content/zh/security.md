## 步骤 1：限制 Key 影响范围

每个客户端使用独立 Key，设置合理额度、有效期和周期限额。只有出口 IP 固定时才设置 IP 白名单。

## 步骤 2：安全保存

Key 放在用户级环境变量、操作系统密钥存储或服务器秘密管理器。不要放在浏览器前端、角色卡、世界书、截图、工单、聊天消息或 Git 仓库。

## 步骤 3：轮换和吊销

怀疑泄露时先停用旧 Key，创建新 Key，更新客户端并完成最小验证。检查用量中的异常时间、模型和来源 IP。

## 脱敏规则

示例统一用 `sk-demo-...`。诊断日志只保留 Key 前后少量字符且优先完全删除。不要用 URL 查询参数传递 Key；代理和浏览器历史可能记录完整 URL。定期清理旧环境变量和客户端配置备份。
